# Quiz_game

A command-line quiz game written in Python. Answer questions, see your score, and track your best result across games.

## Features

- Random selection and order of questions
- Answers ignore capital letters and extra spaces
- Score shown at the end of each game
- Score history saved to a file, with the best score displayed
- Unit tests for the best-score logic

## How to run

1. Install Python 3.
2. Download `Quiz_game.py`.
3. Open a terminal in the same folder and run:

```
python Quiz_game.py
```

## How to run the tests

```
python quiz_game_test.py
```

You should see `OK` at the end.
